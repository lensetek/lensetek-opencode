Kenapa Lensetek?

Di-build di atas ekosistem open source yang sudah terbukti, dengan distribusi yang rapi.

Dua agen bawaan

Beralih antara agen build (full access) dan plan (read-only) cukup dengan tombol Tab.

Subagent general

Panggil @general untuk pencarian & tugas multistep yang kompleks di dalam sesi yang sama.

Multi-platform

Biner native untuk macOS, Linux, dan Windows — termasuk varian musl & baseline.

Semua jalur install

Install script, npm, Homebrew, Scoop, dan Chocolatey — auto-update mengikuti rilis terbaru.

About Lensetek

Lensetek lahir dari kebutuhan tim pengembangan yang ingin agent AI yang bisa benar-benar bekerja di dalam workflow sehari-hari: coding, otomasi, riset, sampai tugas administratif — tanpa meninggalkan terminal.

Kami mengambil fondasi open source yang sudah matang, memberi lapisan distribusi yang konsisten di setiap platform, dan mengkurasi kumpulan skill & template agar pengguna bisa langsung produktif. Proyek ini tetap terbuka: kode, rilis, dan pipeline publish-nya semuanya tersedia di GitHub.

Open source. Terminal-first. Siap dipakai di timmu.

Install

Pilih jalur yang paling nyaman. Semua mengarah ke rilis terbaru.

curl / bash curl -LsS https://raw.githubusercontent.com/lensetek/lensetek-opencode/dev/install.sh | bash
npm npm i -g lensetek
Homebrew brew install lensetek/tap/lensetek
Scoop scoop bucket add lensetek https://github.com/lensetek/lensetek-opencode
Scoop scoop install lensetek
Chocolatey choco install lensetek
