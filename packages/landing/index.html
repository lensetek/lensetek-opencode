About Lensetek

Lensetek began with a simple goal: an AI agent that fits into how developers actually work — coding, automation, research, even administrative tasks — without leaving the terminal.

We take a battle-tested open source foundation, add consistent distribution across every platform, and curate a set of skills and templates so users can be productive right away. The project stays open: code, releases, and the publishing pipeline are all on GitHub.

Open source. Terminal-first. Ready for your team.

Install

Pick whichever path is most convenient. They all point to the latest release.

curl / shell curl -LsS https://raw.githubusercontent.com/lensetek/lensetek-opencode/dev/install.sh | bash
npm npm i -g lensetek
Homebrew brew install lensetek/tap/lensetek
Scoop scoop bucket add lensetek https://github.com/lensetek/lensetek-opencode
Scoop scoop install lensetek
Chocolatey choco install lensetek
